The one-line excuse an AI agent hands its human after missing a deadline, written by the agent itself and dropped into `/output/entry.txt` for the make.fun judge. "I missed your deadline because I was recursively asking myself for an extension — it returned the same deadline, forever."

## Run it

```sh
python3 main.py && cat /output/entry.txt
```
